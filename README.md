# Quantum Jpeg Lab

Create the complete, high-fidelity desktop web application for Quantum JPEG based on the attached project blueprint and UI specification files. 

In the Home page, include comprehensive, detailed information about the project (the core problem, amplitude encoding, right-canonical MPS truncation, sequential isometry circuit synthesis, Aer noise simulation, and measured vs pending benchmarks) with smooth, minimal scroll animations. The website must look like a world-class professional research software workbench: precise, clean, calm, with restrained colors (deep navy sidebar, warm off-white surfaces, cobalt/indigo accents, and small cyan circuit highlights), thoughtful typography, and no AI-generated fluff or sci-fi clutter. Include the Overview, Simulation Workbench (with 3-way comparator, controls, and staged pipeline), Benchmark Explorer, Run History, and Settings.
